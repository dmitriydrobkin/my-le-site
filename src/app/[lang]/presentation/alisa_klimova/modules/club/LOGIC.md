# Модуль: Будущий закрытый клуб "Меню" (В ПРОЕКТЕ)

## Описание
Будущий сложный функционал (после запуска основного сайта). База рецептов по подписке (похоже на mirecipes.ru).

## Функционал
- Авторизация и регистрация.
- Рекуррентная подписка (PRODAMUS).
- Авто-блокировка доступа при неоплате.
- База рецептов.
- Поиск и фильтрация (категории, ингредиенты).
- Избранное.
- Еженедельное готовое меню.
- Конструктор меню на неделю пользователем.

## Варианты реализации
1. Личный кабинет Tilda.
2. Telegram Mini App / Web App (максимальное удобство для использования на кухне).
