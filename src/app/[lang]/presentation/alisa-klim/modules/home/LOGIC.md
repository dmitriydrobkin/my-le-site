# Модуль: Главная страница (Маркетинговая структура)

**Проверка на соответствие ТЗ пройдена:** Все 8 обязательных пунктов из PDF-документа (кто я, с чем работаю, направления, продукты, консультации, материалы, отзывы, соцсети) полностью интегрированы в структуру и усилены маркетинговой логикой AIDA.

## Блок 1: Первый экран (Внимание)
*   **Визуал:** Крупное, теплое фото Алисы с улыбкой.
*   **Надзаголовок:** Алиса Климова • Холистический нутрициолог
*   **Заголовок (H1):** Здоровый рацион вашего ребенка — без слез, уговоров и "медицинской стерильности".
*   **Подзаголовок:** Помогаю выстроить систему прикорма и питание для всей семьи, чтобы дети ели с аппетитом, а мамы перестали тревожиться.
*   **Кнопка:** «Выбрать решение» (якорь к блоку продуктов).

## Блок 2: Идентификация проблемы и "Потеря выгоды" (Интерес)
*   **Заголовок:** Узнаете себя?
*   **Карточки:**
    1. Каждый вечер ломаете голову: "Что приготовить завтра, чтобы он(а) это съел(а)?"
    2. Ребенок-малоежка: ест 3 продукта, ждет сладкое.
    3. Частые простуды в садике, тревожные анализы.
    4. Страх первого прикорма (боязнь заложить неверные привычки).
*   **Триггер:** Пока вы готовите отдельно для ребенка и уговариваете съесть ложечку, вы теряете время, силы и упускаете возраст, когда здоровые привычки закладываются легче всего.

## Блок 3: Решение / Авторитет (Желание)
*   **Заголовок:** Питание не должно быть полем боя. Я покажу, как иначе.
*   **Факты:** ТОП-10 нутрициологов РФ 2023, выпускник МИИН, мама.
*   **Текст:** Мой подход базируется на физиологии, психологии и любви. Никакого пищевого насилия и поиска "пыльцы единорога".

## Блок 4: Витрина / Маршрутизатор (Действие)
*   **Заголовок:** С чем я могу помочь прямо сейчас?
*   **Категория 1:** Малышам (до года) - Курс "Прикорм вместе".
*   **Категория 2:** Для всей семьи - Проект "Меню", Книга рецептов.
*   **Категория 3:** Индивидуальные запросы - Консультации (Дети, Беременность, Мама+Малыш).

*   *Tilda Feeds* с 3 последними статьями из блога.
