## Что содержит каждый файл

Каждый файл страницы содержит:

1. **Метаинформация** — URL, цель страницы, целевое действие
2. **Блоки** — пронумерованные секции страницы (сверху вниз)
3. **Элементы каждого блока** — таблицы с колонками:
   - `#` — Уникальный ID элемента (например, `2.1c`)
   - `Элемент` — Название (Заголовок, Кнопка, Фото, Текст...)
   - `Тип` — HTML-тип (H1, H2, p, button, img, ul > li...)
   - `Текст / Содержимое` — Точный текст для вставки в Tilda
   - `Стиль` — Рекомендации по оформлению (шрифт, размер, цвет)
4. **Связи (ссылки)** — Таблица: какой элемент ведёт на какую страницу/блок
5. **Маркетинговая логика** — Зачем этот блок существует и какую задачу решает
6. **Заметки для верстки** — Технические рекомендации для Tilda
7. **Визуальная схема** — ASCII-карта порядка блоков на странице

## Дизайн-система

> **Полная дизайн-система вынесена в отдельный файл:**

### Быстрая сводка (ключевые токены):

| Элемент | Значение |
|---------|----------|
| Карточки: скругление | `14px` (мягкие, не «бабл») |
| Фото внутри карточки | `10px` + padding 12px от краёв |
| Hero-фото | `20px` |
| Кнопки CTA | `100px` (pill) |
| Бейджи / Теги | `6px` (строгие, не pill) |
| Тень карточки | `0 1px 3px rgba(0,0,0,0.04), 0 4px 12px rgba(0,0,0,0.04)` |
| Шрифт заголовков | Cormorant Garamond (serif, кириллица ✅) |
| Шрифт текста | Manrope (sans-serif, weight: 300, кириллица ✅) |
| Основной цвет | Оливковый `#4A5544` |
| Акцентный цвет | Терракота `#C4724E` |
| Фон страниц | Кремовый `#FAF7F2` чередуется с `#F2EDE5` |

## Порядок сборки в Tilda (рекомендуемый)

1. **Настроить проект:** Домен, HTTPS, Google Fonts (Cormorant Garamond + Outfit)
2. **Собрать глобальные компоненты:** Navbar + Footer (`06_global.md`)
3. **Собрать Главную:** `01_main.md` — блок за блоком
4. **Собрать Консультации:** `03_consultations.md` — это главная конверсионная страница
5. **Собрать Продукты:** `04_products.md` — вторая конверсионная страница
6. **Собрать Обо мне:** `02_about.md` — страница утепления
7. **Собрать Статьи:** `05_articles.md` — после получения контента от Алисы
8. **Подключить оплату:** PRODAMUS → кнопки «Купить» на странице Продуктов
9. **Юридические страницы:** Оферта + Политика конфиденциальности (шаблоны)
10. **Тестирование:** Мобильная адаптация, все ссылки, дисклеймеры
