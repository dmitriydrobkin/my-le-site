# Архитектура проекта

## Текущий этап: Сайт-визитка с магазином
- **Платформа:** Tilda
- **Дизайн:** Индивидуальный дизайн (Zero Block) для основных блоков. Стандартные блоки для удобства редактирования (лента статей, витрина товаров).
- **Интеграции:**
  - Оплата: PRODAMUS
  - Аналитика: Яндекс.Метрика
  - Поиск: Встроенный поиск Tilda (сквозной по сайту, статьям и продуктам)
- **Бюджет:** $350 (зафиксировано)
- **Оплата:** P2P перевод (РФ карта -> биржа -> счет в Европе). Формат: 50% предоплата, 50% после сдачи.
- **Сроки запуска:** Сентябрь - Октябрь (с учетом отпуска клиента 1-10 сентября).

## Будущий этап: Закрытый клуб «Меню для ребёнка и семьи»
- **Формат:** Личный кабинет на сайте (Tilda) ИЛИ Telegram Mini App / Web App (с авторизацией в 1 клик).
- **Логика работы:**
  - Рекуррентная подписка.
  - Доступ к базе рецептов при активной подписке. Автоматическое закрытие при окончании.
  - Поиск и фильтрация рецептов по категориям/ингредиентам.
  - Еженедельные готовые меню.
  - Страница рецепта.
  - Избранное и сборка собственного меню на неделю (в перспективе).
